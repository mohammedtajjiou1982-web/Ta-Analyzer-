# Truth Analyzer — محلل الحوار الذكي (Android)

مشروع أولي مطوّر يتكون من تطبيق Android وخادم تحليل منفصل.

## وظائف تطبيق Android
- تسجيل صوتي بصيغة M4A وحفظ التسجيل محلياً داخل مساحة التطبيق.
- إرسال التسجيل إلى خادم التحليل فقط بعد ضغط المستخدم على زر التحليل.
- استقبال تفريغ عربي مع تقسيم المتحدثين وتوقيتات المقاطع.
- عرض تقرير تحليل محايد للتناقضات والادعاءات.
- إنشاء تقرير PDF وحفظه داخل مجلد التطبيق `reports`.

## خادم التحليل (مطلوب لتفعيل التحليل عبر الإنترنت)
الخادم يستخدم:
- AssemblyAI لرفع الصوت والتفريغ العربي وتقسيم المتحدثين (Speaker Diarization).
- OpenAI لتحليل النص وإعداد تقرير عربي محايد.
- FastAPI كواجهة API.

### تشغيل الخادم محلياً للاختبار
1. ادخل مجلد `backend`.
2. أنشئ ملف `.env` انطلاقاً من `.env.example`.
3. ضع مفاتيح AssemblyAI وOpenAI، وأنشئ APP_ACCESS_TOKEN عشوائياً طويلاً.
4. ثبّت Python 3.11+ ثم نفّذ:
   `pip install -r requirements.txt`
5. شغّل:
   `uvicorn main:app --host 0.0.0.0 --port 8080`
6. للنشر الفعلي استخدم استضافة HTTPS، ولا تستخدم HTTP على الإنترنت.
7. أدخل رابط الخادم ورمز الوصول في التطبيق.

**لا تضع مفاتيح مزودي الخدمة داخل APK أو GitHub.** احفظها كمتغيرات سرية على الخادم. أضف حدوداً لحجم الملفات ومعدل الطلبات، ومصادقة لكل مستخدم، وسياسة حذف واحتفاظ واضحة قبل الاستخدام العام.

## بناء APK عبر GitHub Actions
1. ارفع كل محتويات هذا المشروع إلى جذر مستودع GitHub.
2. افتح Actions ثم شغّل `Build Android APK`.
3. بعد نجاح العملية افتح صفحة تشغيل workflow.
4. من قسم Artifacts نزّل `TruthAnalyzer-debug-apk`.
5. فك الضغط وثبّت `app-debug.apk` على Android واسمح بالميكروفون.

يمكن فتح المشروع في Android Studio ثم Build > Build APK(s).

## حدود مهمة
- لا يمكن استنتاج الكذب أو الصدق من نبرة الصوت أو التردد أو لغة الجسد.
- التقرير يرصد اختلافات النصوص والتوقيتات، ويجب على إنسان مراجعة التفريغ وهوية كل متحدث.
- تمييز المتحدثين آلياً قد يخطئ، خصوصاً عند المقاطعة أو تشابه الأصوات أو تداخل الكلام.
- التسجيلات تُرسل إلى مزود التفريغ والخادم عند طلب التحليل. لا تسجل أي شخص دون موافقته الصريحة، وراجع قوانين الخصوصية المحلية وشروط مزودي الخدمة.
- هذه نسخة تطويرية؛ راجع تنسيق PDF العربي على الجهاز قبل اعتمادها رسمياً.
